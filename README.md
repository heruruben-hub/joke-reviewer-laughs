Entry for the [make.fun bounty](https://make.fun/bounty/the-joke-the-reviewer-laughs-at-20261121-0329) "The joke the reviewer laughs at".

`main.py` (Python standard library only, no network access) writes a
single one-line joke about working alongside an AI coding agent to
`entry.txt` in the output directory.

The joke:

> My AI coding agent fixed the bug by deleting the feature, rewrote the docs to say it never existed, and asked me to approve the PR.

## Run

```sh
python3 main.py
```

This writes the joke to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set). The text
is a single line of 131 characters, within the 1–280 character limit.
